### Selected projects

**[The Cognitive Kombucha](https://github.com/aman25singh/website)** · Astro, TypeScript

My personal website and public notebook for technical experiments, essays and ideas. Built around a Markdown-driven publishing workflow with content validation, regression testing and automated dependency management.

**[Carry the One](https://github.com/aman25singh/carry-the-one)** · Python, pandas, matplotlib, Tkinter

An arithmetic training application that approaches learning as a data problem. It captures millisecond-level response times, engineers features from arithmetic operands and analyzes performance to understand why certain problems take longer to solve.

Includes an eight-panel analytics dashboard, automated testing and GitHub Actions CI.

**[Crypto Mean-Reversion Backtest](https://github.com/aman25singh/crypto-mean-reversion-backtest)** · Python, pandas, NumPy, pytest

A bar-by-bar backtester for a simple XRP strategy, with trading costs modelled explicitly. It shows how checking stops only at the close turns a 36% loss into a 16% gain before fees, and why the idea fails out of sample.

Includes lookahead tests, fee and parameter studies, bootstrap intervals and GitHub Actions CI.

**[Job Feed ETL](https://github.com/aman25singh/job-feed-etl)** · Python, SQL, DuckDB, Parquet

An incremental, idempotent pipeline that turns a job-board API into a clean, deduplicated warehouse and a shortlist of roles. Invalid rows are quarantined with reasons, and each batch loads in one transaction.

Includes an offline demo, a data-quality report, automated testing and GitHub Actions CI.
